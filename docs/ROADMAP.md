# Character Studio —— 路线图

> 文档最后核查日期：2026-10-15 ｜ 基线提交 `bccec24`（2.27.0 / Sprint 37.1）
> **状态定义**：`进行中`｜`待开始`｜`被阻塞`｜`待验证`｜`已取消`
> **规则**：只有存在明确证据时才标 `已完成`。计划中的任务、未验证的交互、只有静态实现而无测试覆盖的功能，都不算已完整交付。
> 本文中的 UI 方案**全部是候选建议**，未经用户批准，不构成已批准的实施需求。

## 1. 当前阶段

**阶段：本地优先工作台的可用性与一致性收敛（2.x 尾段）。**
特征：不新增领域，专注把已有界面的一致性、验证覆盖与文档治理补齐；同时把 UI 层面的设计评估交接出去。

## 6. 每次后续开发结束后需要更新的文档

| 变更类型 | 必须更新 |
| --- | --- |
| 任何源码改动 | `CHANGELOG.md`（含**验证边界**：哪些是实测、哪些未验证）、`src/config/version.ts`（若发布新版本） |
