- 2.37.1 完成了移动端导航、首屏密度与 320px 布局收尾。
- 2.38.0 加入离线灵感工作室，并修掉返回来源、图谱默认、长名称表格与时间线弹窗等稳定性问题。
- 下一阶段的重心是**真机验收**与**新领域探索**，而不是继续打磨现有页面。

## 4. 已取消 / 不再计划

| 项 | 原因 |
| --- | --- |
| 云端同步与账号体系 | 与「本地优先、不上传角色资料」的定位冲突；跨设备使用导出的完整备份 |
| 独立「角色标签」系统 | 与性格标签重复，已在 2.x 早期删除，保留性格标签为唯一标签 |
| 「进入页面自动展开搜索」偏好 | 与「进入页面搜索栏关闭」的不变量冲突 |
| `hideLowPriority` 开关 | 与 `showUpdatedTime` 管同一件事，已删除字段并迁移 |
| 完整 CJK 字体嵌入 PDF | 体积代价过大；采用子集 + 缺字提示 |

## 5. 文档维护规则

1. 任何源码改动 → `CHANGELOG.md`，写明验证边界。
2. 版本发布 → 更新 `README.md` 版本行与 `PROJECT_STATUS.md`。
3. 数据模型 / 存储 / 导入导出变化 → 同步 `DATA_FORMATS.md` 与相关用例。
4. 规划项只有经过确认并开工后才改为「进行中」；完成前不改写为已实现。
5. 新增方向先加到这里，再决定是否进入某个 Sprint。
