## C-02 `CHANGELOG.md` 2.59.6 写入了已被推翻的结论

- **位置**：`CHANGELOG.md:3`。
- **原文**：`375px 下最左节点本身已在视口外（left = -20），姓名的左侧外置被裁掉 20px。`
- **反证**：2.59.6 收尾实测同一场景，环边界为屏幕 `24..351`（视口 375），节点并未越界；`left = -20` 在那个探针会话里无法复现。
- **错误类型**：把一次测量读数当成产品事实写进发布记录。
- **建议修正**：改为「左侧姓名在极靠边时会向右翻转入环内」，去掉 `left = -20` 的因果断言；并加一句「越界读数为探针状态问题，未复现」。
- **修正前置**：无（纯订正）。
