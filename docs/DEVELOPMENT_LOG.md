## 4. 阶段 3：1.x 与 2.x 的领域化（1.0.0 – 2.0.1）

### 4.1　1.0.0（Sprint 9.0）—— 本地优先工作台成为可发布基线

这一版**没有加新功能面**，做的是「把已有的 1.0 做到敢发布」：

- 修复两处圆角控件改了不生效；修复主按钮 hover 无反馈（`--primary-hover` 与 `--primary` 曾被赋成同一个值）；深色模式原生下拉面板发白（缺 `color-scheme`）。

- 数据安全：清空数据与导入文件**先写自动快照**，设置页提供恢复入口。
- **测试从 0 到 51 个**（vitest + happy-dom + fake-indexeddb），接入 CI 在构建前执行。
- 发布自动化：push `main` → typecheck → test → build → 部署 GitHub Pages；构建注入 commit 与时间戳。

### 4.2　1.1.0 / 1.2.0 / 2.0.0 —— 三个领域

| 版本 | 领域 | 关键设计约定 |
| --- | --- | --- |
| 1.1.0（9.1） | **角色关系网** | 关系是**独立集合**而非写进角色记录（一条边属于两个角色）；8 种类型；点击节点进入该角色展示页 |
| 1.2.0（9.2） | **世界观时间线** | 支持**架空历法**：事件同时带可排序的真实日期与可选的纪年标签，**排序永不依赖标签** |
| 2.0.0（10.0） | **世界观管理** | 地点 / 势力 / 种族 / 物品 / 概念，支持层级（国家下辖城市）、标签与角色关联 |

三个领域共同的设计约定：

- **删除的语义是「断开」而非「连带删除」**：删角色会从事件与世界观条目中移除该角色的关联，**但事件与条目本身保留**；删世界观父级时子级变为顶层而不是一起消失。
- **读取即修复**：损坏的存储值、缺关键字段、未知类型、重复 id、悬空引用、成环层级都在读取时被安全处理。
- **空壳开关不再存在**：`experimentalRelationshipGraph` / `experimentalTimeline` 此前「已声明、界面上展示、却从未生效」，现在真正控制入口；`worldManager` 为新增同类开关。

### 4.3　2.0.1（10.1）—— About 显示过期版本号

根因：Version / Sprint 读的是 `localStorage` 里的 `developerSettings.project`，而它只在首次运行时取一次默认值，之后永久驻留。
修法：版本一律取自编译进包的常量；开发者中心这五个字段改为**只读**（允许编辑它们正是该 bug 的成因）。用户已存的旧值不删除，只是不再被任何界面读取。

## 6. 阶段 5：数据可靠性 → 架构收敛 → 界面返工（2.12.0 – 2.27.0）

### 6.1　阶段 A：数据与状态可靠性（2.12.0，Sprint 22.1）

| 项 | 内容 |
| --- | --- |
| 调查更正 | 规划初稿写「引用清理发生在下次挂载而不是删除时」，读码后事实是：**单删路径一直会清理**，**批量删除不会**；三个域页面各自在挂载时清理自己的域，存储层的 load 不做自愈。残留风险是**在这个窗口内导出的备份会带解析不到的 id，而导入校验会丢弃它们**（恢复时静默少东西） |

## 7. 累计的测量与方法教训（可复用的纪律）

从 2.5.0 起，几乎每一版都在「验证动作本身产生了假信息」上踩过一次。归纳成可直接执行的四条：

1. **先验证观测点有没有区分度**，再拿它去测被测行为。已踩过：观测点选错（把恒存在的容器当状态指示器）、对照起点不同（profile 停在别的视图）、空 DOM 让所有断言为真。
2. **断言的对象要和动作的对象是同一个。** 2.27.0 的滚轮验证第一次把点打在 `y=560`，而画布只到 `y=540`，断言却校验「预记录的中心点」→ `inside: true` 通过、结论却是错的。**并且**：合成 `WheelEvent` 不执行默认行为，只有真实 CDP `Input.dispatchMouseEvent` 能回答「页面会不会滚」。
3. **改动与验证必须分成两轮。** 同一条回复里的工具调用会并行执行，编辑与读取同批会读到旧内容（曾把「还没落盘」误判成「没生效」，三次）。做结构化改写前先备份。
4. **报告前先把可疑读数拆成原始几何。** 1440 下的 `rows: 2` 与 `overflowInside` 是度量假象：5 个控件的 `top` 是 354/354/354/**351**/354（主按钮高 3px 被「按 top 分组」算成两行），而绝对定位的隐藏 file input 与浮层污染了 `scrollWidth`。

另外三条工程性纪律：

5. **脏工作树会改变构建产物**（提交号带 `-dirty` → 内容哈希变化）→ 必须**先提交、再重建、再跑 `verify:deploy`**。
6. **图标按钮没有文字** → 用 `aria-label` 查找，并加「空结果即返回错误」的前置断言，否则探针会拿到空结果并「看起来没问题」。
7. **`git commit -m` 里的反引号会被 zsh 当命令替换吞掉** → 用 `-F file`。
