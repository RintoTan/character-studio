# Character Studio —— 功能清单与状态

> 最近核对：2026-10-19（2.38.0 / Sprint 48）｜ 依据：当前源码 + `vitest` 549 例 + `verify:browser` 68 项
> **状态定义**：`已实现`＝入口可达且行为完整；`部分实现`＝主体可用但有明确缺口；`未实现`＝不存在；`需真机`＝桌面环境无法给出结论。
> 本文只列**用户可见或影响数据**的功能；逐版本变更见 `CHANGELOG.md`。

---

## 1. 角色管理与 Dashboard

| 功能 | 状态 | 行为与边界 |
| --- | --- | --- |
| 卡片 / 列表视图 | 已实现 | 视图偏好持久化；两种视图共享同一份角色与操作 |
| 搜索 | 已实现 | 匹配名称、职业、世界观、性格标签 |
| 排序 | 已实现 | 最近编辑 / 创建时间 / 名称；收藏不更新 `updatedAt` |
| 筛选 | 已实现 | 世界观、性别、视觉风格；与搜索叠加 |
| 收藏 / 草稿 | 已实现 | 独立的范围视图；草稿可提升为正式角色 |
| 置顶 | 已实现 | 仅影响排序，不改数据时间 |
| 批量操作 | 已实现 | 选择、全选、复制、删除、收藏、导出；进入 / 退出批量模式有明确状态 |
| 批量编辑 | 已实现 | 世界观、标签、收藏等字段可分别选择；空值不写入 |
| 分组与定位 | 已实现 | 角色较多时按世界观分组；分组条横向滚动，被裁切的一侧显示渐隐 |
| 删除撤销 | 已实现 | 10 秒内恢复角色与被清理的关系 / 引用；单删、批删、编辑器删除一致 |
| 空状态 | 已实现 | 无角色、搜索无结果、筛选无结果分别说明 |
