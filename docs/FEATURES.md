## 12. 关系画布工作室（Sprint 50，已随 2.60.0 发布候选交付）

> 下列能力均已实现并有本地验证；完整浏览器套件的执行范围见 `docs/TESTING.md`。


- 沉浸式工作室：顶栏（退出 / 撤销重做 / 保存状态）、可收起的角色与属性抽屉、底部工具坞；手机端为底部弹层。进入时按新空间重新适配，退出还原进入前视角。
- 局部外观：单节点边框色与底色、单条关系线颜色 / 粗细 / 线型，按稳定 id 持久化，可一键恢复默认。
- 姓名字号：0.8–1.8 倍率，与显示设置的小/中/大叠加，绘制与密度判定共用同一字号。
- 人物聚光灯：1 / 2 层邻域高亮，其余淡出；退出后聚光灯淡化清除，不影响搜索聚焦与 hover。
- 关系类型透镜：按类型多选，其余淡出且不带标签，只改显示。
- 视角书签：保存 / 跳转 / 重命名 / 删除，只存视角。
- 导出：PNG / SVG ×（全部内容 / 当前视图 / 选中区域），全部内容按世界坐标边界计算，含局部样式、分组与底色；最长边 8192px 封顶。

## 13. 关系网使用指南（2.41.0 / Sprint 50）

普通关系网画布下方的独立指南区块：区块标题、单张提示加翻页，四张分别讲选择与移动、画布导航、整理、外观与导出。它落在页面文档流里，与画布各自独立，没有卡片边框、分隔线或悬浮层。

- 一次只显示一条提示，层级为「区块标题 → 技巧标题 → 正文 → 补充提示」，桌面正文最大阅读宽度 720px，手机自然换行。
- 四张是闭环：`1 → 2 → 3 → 4 → 1`，末张继续点回到首张，按钮从不禁用。
- 键盘左右方向键只在指南内部获得焦点时生效，不占用画布或文本输入的方向键。
- 默认展开，没有收起入口；旧版 `sessionStorage`（`character-studio.graph-guide`）里的 `collapsed` 会被清除，不会让新方案首次呈现为空。指南状态不进入角色数据、布局数据或备份。
- 全屏编辑模式不渲染指南，保持沉浸；画布面积不受影响。
- 320 / 375 / 430 / 1024 / 1440 均无横向溢出，提示切换不改变页面高度。

## 14. 时间线与世界观使用指南（Sprint 50 收尾）

`GuideBlock` 是三个页面共用的扁平指南结构（标题、单张提示、页码与两个圆形翻页按钮），时间线与世界观不再各写一份；关系网（§13）、时间线、世界观只是传入四张文案。

- 时间线四张：创建事件、日期排序与年份分组、关联角色与地点、搜索筛选与阅读。
- 世界观四张：创建设定条目、分类与父子层级、关联角色、搜索筛选与详情阅读。
- 文案只描述已实现的操作：年份导航只跳转不筛选；删除上级条目时下级变顶层；筛选不修改数据。
- 关系网文案按输入设备切换：macOS 用 Command、Windows/Linux 用 Ctrl、手机只讲点按、多选工具与双指缩放，不出现 Shift / Ctrl / 中键。
- 阅读区块在普通文档流内、与 Footer 留出安全间距，320 / 375 / 430 / 1440 均无横向溢出。

## 15. 整理事务与画布强调（Sprint 50 收尾）

- 状态机：`idle → previewing → committed`。`beginArrange` 只保留首次基线，`cancelArrangeSession` 恢复坐标、视角与选择，`commitArrangeSession` 只由确认调用，`proposalChanges` 让“没有移动”的提案不写撤销记录。
- 预览期间切换布局、平移缩放、点选都允许；拖动节点不写坐标。切换其它任务、关闭抽屉、进出全屏都会先回滚。
- 强调优先级：`选择 > 聚光灯目标 > 搜索命中 > 邻居 > 透镜 > 背景`，节点与连线都输出 `data-emphasis`；所选对象不被透镜压暗。
- 姓名在屏幕字号低于 5.5px 时隐藏（6.5px 恢复），选中/聚焦/悬停保留到 4px；关系标签低于 6px 不绘制。导出按样式绘制，不受阅读阈值影响。
